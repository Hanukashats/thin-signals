# Donor/framework matrix — research snapshot 2026-09-02

This file identifies patterns to adopt, not a mandate to embed every framework.

| Donor | Strongest contribution to GoalOps | Use as |
|---|---|---|
| Agent Skills open specification | portable `SKILL.md` package + progressive disclosure | canonical skill envelope |
| Cursor `/goal`, skills, subagents | persistent objective, custom modes, subagents, isolated execution | native Cursor adapter |
| Superpowers | disciplined spec/plan/TDD, subagent-driven development, two-stage review, evidence over claims | methodology donor |
| gstack | explicit engineering/CEO/design/security/release lenses, adversarial review, staged review gates | role/gate donor |
| GitHub Spec Kit | constitution/spec/clarify/plan/tasks/converge; broad agent integration architecture | spec-driven portability donor |
| BMAD Method v6 | mature specialist-role catalog, adaptive workflows, party/team modes | role taxonomy donor |
| Ruflo | cross-agent swarm orchestration, hooks, routing, topology, autonomous loops | optional runtime substrate/donor |
| Claude Code | subagents, hooks, agent teams, batch/worktrees | adapter + team-pattern donor |
| OpenCode | explicit primary/subagent manifests and granular permissions; Agent Skills compatibility | adapter donor |
| Hermes | Agent Skills, isolated/parallel subagents, Bot Mode specialists, MCP | adapter donor |
| Codex | multi-agent/worktree operation, skills, automations; repo-as-system-of-record harness discipline | adapter/harness donor |
| Microsoft Agent Framework | sequential/concurrent/handoff/group-chat/Magentic orchestration, checkpointed workflows | orchestration pattern reference |
| LangGraph | stateful multi-actor graph and supervisor/swarm patterns | stateful workflow option |
| CrewAI | crews/flows, hierarchical processes, guardrails/observability | comparison/reference |
| Google ADK | workflow vs dynamic routing patterns, multi-agent/evaluation/runtime portability | comparison/reference |
| OpenAI Agents SDK | manager/handoff/code orchestration, guardrails, provider-agnostic patterns | comparison/reference |
| MetaGPT | SOP-as-code and software-company role decomposition | historical pattern donor |
| ChatDev | virtual software-company role decomposition | historical comparison |
| AFlow | automated search/optimization over code-represented workflows | offline Evolution Engine donor |
| DSPy | prompt/program optimization (MIPROv2/GEPA/etc.) | offline eval/optimization donor |
| Agent Zero | dynamic subordinate agents, skills/MCP/A2A | extensibility comparison |

Verified in research snapshot:
