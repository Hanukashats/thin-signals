# Changelog

## 1.2.1 — 2026-09-08

Pre-install correctness and portability patch based on a self-run + independent red-team audit.

- Use strict common-denominator frontmatter (`name`, `description`) for portable Codex/Hermes/Agent Skills installation.
- Replace `Evidence before ideas` with `Evidence before commitment, not before imagination`; add controlled speculative `E0` hypothesis lane.
- Make archetype an early routing decision and make deterministic readiness archetype-aware.
- Change G6 from universal moat/durability requirement to credible adoption/switch reason; keep durability as a scored strategic pillar.
- Add evidence-linked gate objects with confidence/scope; weak FAIL signals trigger verification instead of terminal kill.
- Remove universal scalar Rank from scorer output; add separate quality/readiness orders and Pareto frontier.
- Add optional evidence replication fields and conservative suggested-maturity audit.
- Make routing/adaptive references conditional rather than mandatory context on every run.
- Add forced-decision/deadline behavior, output tiers, single-writer evidence ledger, and opt-in global founder profile.
- Fix provenance-lock path typo.
- Add blind behavioral eval pack for Hermes/Codex/Astra follow-up.
- Replace residual universal “first 20 prospects” and literal 10× heuristics with archetype/decision-relative access and material-step-change tests.
- Make red-team, routing, output, and validation wording archetype-neutral where payment/buyer language was not universally applicable.

## 1.2.0 — 2026-09-08

- Recast the workflow from a visually linear phase sequence into an adaptive decision DAG.
- Added `CONTINUE / SKIP / JUMP / EXIT` transitions plus `RECYCLE` for local pivots.
- Made FAST/STANDARD/DEEP research-budget ceilings rather than mandatory path lengths.
- Added stakes/reversibility routing so cheap two-way bets use lighter process than one-way/high-risk commitments.
- Added cheap-fatal-dependency preflight before broad market research.
- Added decision-stability, test-beats-research, strong-commitment, inaccessible-information, and two-wave stall early exits/jumps.
- Added skip taxonomy: SAFE-SKIP, DEFERRED-DEBT, FORBIDDEN-SKIP.
- Reintroduced useful v1.0 constraints as conditional presets rather than universal gates (including optional ~72h wedge filter and existing-spend bias for RAPID-CASHFLOW).
- Made market sizing, failure archaeology, multi-solution generation, and full red-team explicitly conditional.
- Added internal automation and non-commercial/OSS route semantics.
- Added 30-scenario qualitative flow simulation and 18-case deterministic routing regression harness in the development package.
- Preserved the four-layer gate/quality/evidence/readiness model from v1.1.
