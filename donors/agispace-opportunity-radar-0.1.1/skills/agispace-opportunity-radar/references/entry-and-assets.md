# Окно участия и активы

Сначала форма участия: исследование, услуги, свой продукт, интеграция, партнёрство, лицензирование, частная доля или биржевая бумага. Один момент может быть ранним для покупки завода и подходящим для инженерных услуг.

Четыре разные шкалы времени: научная зрелость; промышленное масштабирование; коммерческие заказы/деньги; ожидания финансового рынка. TRL не измеряет прибыльность массового производства.

| Стадия | Обратимый шаг | Триггер увеличения участия |
|---|---|---|
| Лаборатория | Наблюдение/воспроизведение | Независимый результат, целевой performance |
| Пилот/квалификация | Ограниченный PoC/услуги | Клиентская среда, экономика/сроки |
| Первые заказы | Платный пилот/интеграция/diligence | Выполнение, повторение спроса, капитал |
| Масштабирование | Тиражирование/партнёрство | Мощность, yield, unit economics |
| Устранение дефицита | Пересмотр тезиса | Новый подтверждённый ограничитель |

Это не универсальный календарь доходности.

Для актива проверить:
1. Юрлицо → материнская структура → инструмент/биржа/ticker/ISIN/права. Не угадывать ticker.
2. Публичность, ликвидность, валюта, доступ брокера/юрисдикции. Private valuation не котировка.
3. Доля направления в выручке/прибыли, backlog/отмены, capex, долг, cash runway, dilution.
4. Сценарии спроса, мощности, yield, цены, маржи, капитала; мост к свободному денежному потоку. TAM не выручка.
5. Текущая оценка с временем/источником цены; что уже заложено в ожидания. Без цены/отчётности readiness UNKNOWN.
6. Bear/base/bull, допущения, чувствительность, отмена тезиса. Вероятности только явно субъективные и обоснованные; не делать ожидаемую доходность из произвольных весов.
7. Портфельная роль и допустимый убыток. При неизвестных личных параметрах — исследовательская карточка, без персонального размера покупки.

INVESTABLE CANDIDATE FOR DILIGENCE означает кандидата для дальнейшей проверки, не «покупать». При конкретном практическом запросе уточнить издержки/налоги/ограничения по дате и юрисдикции.
Старые тикеры и прогнозы из дайджеста — история, весь тезис проверять заново. Исследование не разрешает сделку или контакт с компанией.
