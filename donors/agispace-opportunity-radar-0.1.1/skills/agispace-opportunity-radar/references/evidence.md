# Доказательства

Claim: ID, текст, тип fact/inference/hypothesis/forecast, scope, evidence_for/against, статус, дата пересмотра. Evidence: точный URL/файл, название, автор/организация, published_at, available_at, fetched_at, locator, короткая выдержка в пределах прав использования. Недоступный первоисточник отметить.

Первичные источники: статья/данные/код, отчёт компании с примечаниями к сегментам, патент, каталог спецификаций, контракт/тендер, регуляторная запись. Пресс-релиз первичен для заявления компании, но не независим для доказательства результата. СМИ и базы полезны для discovery.

Сохранить event_id и origin_group_id. Препринт, статья, GitHub и новости об одном опыте — одно событие. Общая материнская компания, пресс-агентство, соавторы/финансирование могут создавать зависимость. Несколько интервью одного клиента не означают нескольких покупателей. Неизвестную независимость не считать доказанной.

Не смешивать прочитанность источника, силу свидетельства и независимость/репликацию. Для коммерческих claims E0–E4 — opportunities.md; для научных: теория, измерение авторов, независимое воспроизведение, целевой пилот, промышленный результат. Научная статья не доказывает willingness-to-pay.

Искать retraction/correction, неудачную репликацию, отрицательную unit economics, отменённые заказы, заменители. Отрицательный поиск раскрывать через запросы/покрытие; он не доказывает отсутствие.

Для as_of=T использовать только доступную тогда версию. Текущие stars/цены/цитирования непригодны для прошлого прогноза. Неизвестный available_at ограничивает строгий backtest. Количественным claims нужны единицы, период, знаменатель, валюта, допущения. LLM-оценка не первичные данные. Контрдоказательства хранить рядом с тезисом.
