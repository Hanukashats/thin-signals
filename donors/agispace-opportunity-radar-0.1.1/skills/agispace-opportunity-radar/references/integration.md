# Интеграция

Скилл — аналитическая процедура; плагин — её упаковка. Они не создают постоянно работающие коллекторы, брокерский доступ, БД или scheduler.

Начать с web/file tools, JSON evidence/claims и Markdown memo. Независимость от LLM/runtime. Недоступный инструмент заменять исследованием с явным покрытием.

AgiSpace: SearchProvider, DocumentParser, EvidenceStore, ModelGateway, RunStore. Сначала live-проверка endpoints/прав/формата/timeouts/лимитов/стоимости. План не доказывает готовность сервера.

Последний найденный нормативный план — weak_signals_production_architecture_v5.md от 17.09.2026: PostgreSQL + pgvector, Neo4j как производная проекция, Hermes + предметный скилл, Procrastinate, BERTopic + временные признаки + LogisticRegression, React/Refine/Ant Design. OpenCode — кандидат замены после испытаний; LangGraph — резерв. v5 заменяет решения v4; старый v1 с SQLite и без графа сохранён только как история. Это план, не доказательство реализации или live-готовности.

Выбор v5: фиксированная сильная LLM, поиск, проверяемые доказательства, предметный скилл и надёжный harness; без fine-tuning LLM/LoRA/QLoRA в первой поставке. Компактный обучаемый классификатор сохраняется при наличии корректной разметки обоих классов. GEPA — ограниченный офлайн-эксперимент для промптов извлечения/верификации через самостоятельный адаптер; DSPy runtime не обязателен. Holdout, evaluator, source-trust policy, бюджеты и разрешённые модели оптимизатор не меняет. A/B/C/D и достижение метрик пока не подтверждены.

Автономный аналитический скилл может хранить supply-chain в JSON. При интеграции в уже выбранный продукт v5 переиспользовать его PostgreSQL/Neo4j; не откатывать граф и БД к старому v1. GraphRAG — отдельный необязательный механизм. LLM-edge не факт. Финансовый анализ и поиск поставщиков — расширение продукта; не подменять ими критерии банковского ТЗ.

В продукте использовать выбранные PG/S3, а межпроектную Knowledge Factory и длительную оркестрацию подключать по контракту. Один writer run state, идемпотентность, retry caps, budgets, checkpoints. Hermes/OpenCode/Codex не единственное хранилище состояния.

OpenResearch — R&D detector/абляций, не замена ledger, финансовой модели и коллекторам.

Приёмка: evidence связан с claim; независимость учтена; UNKNOWN сохранён; backtest без будущего; retry без дублей; актив без актуальных данных не проходит; смена runtime сохраняет контракт. Расписание создавать только при запросе на автоматизацию.
