# Презентация «Тонкие сигналы» — комплект 29.09.2026

Текущая редактируемая презентация — [Thin-Signals-2026-09-29.pptx](Thin-Signals-2026-09-29.pptx).
Версия для просмотра — [Thin-Signals-2026-09-29.pdf](Thin-Signals-2026-09-29.pdf).
В обеих 15 слайдов / страниц, 16:9. Первый блок сохраняет обязательные
слайды 7–11 организаторского шаблона в позициях 1–5.

Дата комплекта и метаданных документов **29.09.2026** установлена по разрешению
организаторов, о котором сообщил оператор. Фактические даты интеграции,
генерации и проверки исключены из текста и метаданных. Дата комплекта не
утверждает, что проверки проведены в этот день или что материалы уже
отправлены организаторам.

Слайды 2–4 содержат явные поля **[УТОЧНИТЬ]**: персональные данные команды
не предоставлены. Содержательная и техническая часть готова; внешняя подача
требует заполнить [поля команды](2026-09-29-team-fields.txt) реальными данными.

## Что входит

- `2026-09-29-audit.md` — итог проверки и ограничения.
- `2026-09-29-outline.json` — текст слайдов и заметок, включая источники.
- `presentation-verification.json`, `visual-review.md` — структурная,
  шрифтовая и визуальная проверки; SHA-256 итоговых документов.
- `release-evidence.json` — происхождение скриншота, дата комплекта, проверенные
  результаты и явное различие staging / production.
- `typography-review.md` — анализ научного характера и читаемости интерфейса.
- `fonts/` — статические Montserrat Regular/Bold и лицензия OFL; установить
  для одинакового вида при редактировании PPTX. PDF содержит встроенные шрифты.
- `assets/current-three-panels.png` — фактический текущий интерфейс без
  обрезки и изменения пропорций на слайде 14.

Все содержательные тексты и схемы редактируются в PowerPoint. Растровые
элементы — исходная графика организатора, логотипы и скриншот приложения.
Официальный шаблон не продублирован ещё одним большим файлом: его пять
обязательных слайдов сохранены внутри текущего PPTX. Геометрия сверяется
с `template-signature.json`; хэш полного исходного шаблона записан в аудите.
Два исключения — логотипные picture placeholders: слайд 1, shape ID 4;
слайд 2, shape ID 2. Их положение/размер адаптированы под пропорции логотипов.
Геометрия остальных полей и исходные layouts/IDs сохранены.

## Обновление и проверка

Python 3.12+; зависимости — `requirements.txt`. Команды из корня репозитория:

```bash
python docs/presentation/build_deck.py
bash docs/presentation/export_pdf.sh
python docs/presentation/verify_deck.py --outdir /tmp/thin-signals-deck-review --stamp-event-date
```

Сборщик использует первые пять слайдов текущего PPTX как редактируемый
шаблон, сохраняет их, затем пересобирает слайды 6–15. Для пробного вывода
используйте `--output /tmp/Thin-Signals-2026-09-29.pptx`.
Обновление персональных полей первых пяти слайдов сохраняется при пересборке.
Сборщик сохраняет только разрешённую дату комплекта 29.09.2026 в свойствах
PPTX и временных метках ZIP-записей. Проверка контролирует эту политику в
свойствах, заметках и ZIP-содержимом PPTX, а также в метаданных и исходных
байтах PDF; фактические processing timestamps недопустимы. Соответствие
содержания PPTX/PDF и покрытие символов шрифтами проверяются независимо.
Маркеры незаполненных полей на слайдах 2–4 выявляются динамически: заполнение
реальными сведениями не ломает проверку. Отсутствие маркеров не доказывает
правдивость сведений — актуализируйте также заметки, аудит и ручную приёмку.
Регрессии: `python -m unittest discover -s docs/presentation -p 'test_*.py' -v`.

Экспорт использует уже установленный локальный образ LibreOffice, закреплённый
по digest в `export_pdf.sh`; сеть и сервисные каталоги ему не предоставляются.
На другом компьютере можно экспортировать PPTX штатным PowerPoint или
LibreOffice после установки приложенных шрифтов, затем повторить проверку.
Новый экспорт требует нового визуального просмотра всех 15 PNG.

`--stamp-event-date` устанавливает разрешённую дату комплекта в PDF и полностью
перезаписывает файл с удалением прежних Info/XMP объектов; инкрементальное
сохранение (`saveIncr`) не используется. Фактическое время обработки не
записывается в subject, comments или заметки. Изменение метаданных меняет
хэши даже при неизменном виде слайдов. Нельзя переносить старый PASS или хэши
на пересобранные файлы без проверки.

## Замена прежних версий

На момент инвентаризации в Git и SourceCraft не было старых бинарных
презентаций: прежние PPTX/PDF находились только в исторических outbox.
Устаревшие текстовые аудит и outline заменены текущими, PPTX/PDF впервые
добавлены в эту каноническую папку. Исторические outbox сохранены для
восстановления; они не являются текущим комплектом.

`sources/1. Газпромбанк.Тех.pdf` и `sources/8. Yandex Cloud.pdf` — исходные
требования организаторов, поэтому они сохранены.
