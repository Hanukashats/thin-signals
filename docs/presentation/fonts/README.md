# Montserrat для редактирования и воспроизводимого экспорта

`Montserrat-Regular.ttf` и `Montserrat-Bold.ttf` — статические экземпляры
Montserrat 9.000, веса 400 и 700. Сохранены исходные glyph outlines; экземпляры
созданы из официального variable font для корректного выбора веса LibreOffice.
Регулярное начертание ошибочно подставлялось как Thin при прямом экспорте
variable font; статические файлы устраняют этот известный дефект.

Семейство: [официальный Montserrat](https://github.com/JulietaUla/Montserrat).
Лицензия: приложенная `OFL.txt`, SIL OFL 1.1. Copyright в бинарниках:
`Copyright 2011 The Montserrat Project Authors`.

Происхождение экземпляров: проверенная сборка презентации от 01.10.2026,
`outbox/1305367840_1790893410/presentation-work/static_fonts.py`.
SHA-256 и покрытие всех символов текущей презентации занесены в
`../presentation-verification.json`. При редактировании PPTX установите оба
файла. PDF уже содержит встроенные подмножества шрифтов.
