# Живой путь (W3, начат 2026-09-23)

Команда:

```bash
ts run --query "запрос" --limit 3
ts run --query "запрос" --extract    # лабораторный режим, OpenRouter ZDR, model_id пишется в карточку
```

Что делает прогон, по шагам: поиск → снимок (если `--snapshot`) → склейка одного и того же события → контрпоиск зрелости → скоринг → решение, пускать ли в ТОП-15.

Источники поиска: SearXNG, если задан адрес, плюс arXiv, OpenAlex, Crossref, Europe PMC, DOAJ, HAL, OpenReview, GitHub, гранты NSF, NIH и CORDIS, черновики IETF, испытания ClinicalTrials и отчёты SEC. Жёлтая пресса и форумы в этот список не входят. Патентный Lens и реестр Роспатента пока без открытого ключа не подключены. Ворота ТОП-15 те же: находка сама по себе в список не попадает.

Повтор того же запроса при тех же правилах не ходит в сеть ещё раз.

## Почему ТОП-15 может быть пустым

Это не поломка поиска. В прогоне `photonic inference processor` (2026-09-23) все пять источников ответили, 10 документов. В ТОП-15 не попал ни один: у кандидата нет подтверждённого перехода стадии, политика вернула `WATCHLIST`, недобор 15 честный.

В ТОП-15 попадает только карточка, у которой одновременно метка `weak_signal` и решение `RANK_ELIGIBLE`. Зрелое, шум и «просто найдено в поиске» уходят в реестр исключений с причиной.

Если пятнадцати прошедших нет, отдельное окно «Ближайшие к допуску» показывает до 15 находок этого прогона. У каждой — место в очереди, доля пройденных проверок, ступень, на которой встал прогон, и чего не хватает у самой находки. Это не заполнение ТОП-15 и не вероятность спроса.

## Чего этот срез ещё не делает

- Не пишет прогон в PostgreSQL (таблица `runs` есть, запись — следующий шаг).
- Не гоняет PDF через Docling и не считает векторы TEI: склейка событий идёт по DOI и заголовку.
- Не рисует UI.
- Извлечение идёт в OpenRouter только со списком моделей, у которых включена защита: данные не сохраняются и не идут в обучение (`zdr`, `data_collection=deny`). Модель вне списка клиент отвергает. Повтор того же запроса читается из PostgreSQL и в сеть не ходит.

API: `uvicorn ts.api:app --host 127.0.0.1 --port 8095`, затем `POST /v1/runs` с полями `query`, `limit`, `extract`. В ответе статус прогона и метка сигнала лежат отдельно.
