# «Тонкие сигналы»: исследовательский модуль

Срез: 29.09.2026. Начните с **REPORT.md**: методология, 15 карточек, 14 исключений/отложенных решений, 83 источника и конкретные тесты гипотез.

Это работающий прототип исследовательского отбора. Он не подключён к backend и не выполняет автономную проверку патентной свободы, инвестиционных раундов или научной воспроизводимости. Ни один кандидат пока не квалифицирован полностью.

Python 3.8 или новее, сторонние пакеты не нужны. В PowerShell из этой папки:

```powershell
python score.py
python -m unittest -v
python build_report.py
```

В текущем окружении при необходимости используйте `& 'C:/Python38/python.exe'` вместо `python`.

`score.py` читает candidates.json, model.json и sources.json; записывает ranking.json, ranking.csv (UTF-8 BOM) и sensitivity.json. Исходные карточки не меняет. CSV — переносимая таблица рангов, отчёт содержит развёрнутые объяснения.

Свой набор карточек и модель:

```powershell
python score.py --candidates my_candidates.json --model my_model.json --out my_ranking.json
```

Ссылки новых карточек также должны быть зарегистрированы в sources.json. `--out` меняет путь JSON; CSV и sensitivity.json при любом запуске перезаписываются в папке скрипта. Результаты другого режима лучше рассчитывать в копии исследовательской папки.

Для совершенно новых открытий доступен `--stream emergence`: возраст и историческая оценка отключаются, исторический вес переходит к B/E. Финальная таблица отчёта рассчитана в режиме `resurrection`; это разные потоки отбора.

Получение свежих метаданных:

```powershell
python collect_metadata.py --check-dois --query 'Knudsen pump' --rows 3 --until 2026-09-29 --output metadata_new.json
```

Сборщик обращается только к Crossref и Europe PMC. DOI берутся из sources.json. Он сохраняет сетевые ошибки вместо вымышленных результатов. Живой прогон: 43 DOI получены, два поиска Crossref успешны; оба запроса Europe PMC завершились HTTP 503. Пустые сведения об отзыве не означают отсутствия отзыва.

Основные файлы:

| Файл | Назначение |
|---|---|
| REPORT.md | Полный исследовательский результат |
| PLAN.md | Выполненный план и граница работы |
| candidates.json | 15 итоговых карточек и экспертные оценки |
| sources.json | Источники, назначение, доступ и проверенные DOI |
| model.json | Веса, пороги и коммерческие основания исключения |
| score.py | Расчёт и обязательные ворота |
| ranking.csv / ranking.json | Воспроизводимое ранжирование |
| exclusions.json / retired_candidates.json | След отклонений и пересмотра |
| market_search_log.json | 20 выполненных коммерческих запросов и обнаруженные ссылки |
| metadata_snapshot.json / metadata_doi_final.json | Фактически полученные сетевые ответы |
| sensitivity.json | 16 сценариев изменения одного веса |
| test_score.py | Смысловые проверки модели |
| methodology.md / build_report.py | Редактируемая методология и сборка отчёта |

`review_update.json` и `apply_review_update.py` сохраняют второй проход проверки; повторять для обычного расчёта не нужно. `finalize_metadata.py` переносит поля из финального снимка Crossref в реестр источников; это проверка идентичности публикаций, а не научных выводов.

Числа 0–5 — экспертная начальная разметка, не результат обученной модели. Диапазон L–U показывает только вклад отсутствующих данных. Предложенные пороги лабораторных тестов не являются достигнутыми результатами. Неизвестные права или коммерческий статус всегда оставляют HOLD.
