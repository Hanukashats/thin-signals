# Происхождение и полнота

## Сохранённые артефакты

Каталог research/ скопирован из thin-signals-research-2026-09-29 без изменения содержимого исходных файлов. В него входят все 22 обычных файла этого каталога. Исключён только __pycache__: это автоматически восстанавливаемый байткод Python, не источник данных или методики. MANIFEST.json позволяет проверить каждый байт включённых файлов.

Первая работа выполнялась в среде Codex на Windows с PowerShell и Python 3.8. Конкретная ревизия модели, параметры генерации и начальное случайное состояние агента не фиксировались. Подагенты не использовались. Нет требования пользоваться Codex: другой агент может выполнять этот процесс через доступные ему поиск, файловые операции и Python.

Дата информационного среза исходной модели — 2026-09-29. Дата создания пакета и технические сведения о проверке записаны в PACKAGE_INFO.json и validation/.

## Документация, добавленная при упаковке

START_HERE.md, docs/, handoff/, templates/, workflow.json и скрипты проверки подготовлены при передаче эксперимента. Они систематизируют сохранённую методологию и фактические решения. Это не дословный журнал всех сообщений агента.

docs/DECISION_LOG.md — восстановленный по артефактам журнал существенных решений с краткими основаниями. Для событий без сохранённого времени указана логическая последовательность, а не вымышленные часы. Развёрнутые шкалы оценивания и рекомендуемый регламент повторного исследования обозначены как операционное уточнение для следующего запуска; исходные баллы не пересчитывались.

## Что доступно полностью

- Исходные экспертные оценки, веса, пороги, статусы и формулы.
- Все итоговые карточки и пять снятых карточек.
- Причины 14 решений об исключении/отложенной проверке.
- Реестр источников с URL, датами и отметками доступа.
- Сохранённые ответы Crossref и ошибки Europe PMC.
- Журнал 20 конкретных коммерческих запросов с обнаруженными URL.
- Исходный план, полный отчёт, сборщик, ранжирование, чувствительность и тесты.
- Формы и инструкция для повторения на другом агенте.

## Чего в архиве нет

- Полной стенограммы всех промежуточных поисковых вызовов и их полных ответов: она не сохранялась в исследовательские файлы.
- Полных локальных копий всех статей, PDF и сайтов. Включены ссылки, метаданные и краткие сведения о подтверждаемых утверждениях.
- Результатов платного патентного поиска, закрытых инвестиционных баз или ответов технологических офисов.
- Независимых лабораторных воспроизведений, переговоров, сделок или интеграции в backend.
- Исторического бэктеста прогнозной способности весов.
- Полного первоначального состояния каждой карточки до всех правок. retired_candidates.json хранит снятые карточки с уже добавленными основаниями снятия; review_update.json хранит изменения второго прохода.

Отсюда: офлайн можно точно воспроизвести вычислительную часть и отчёт. Нельзя обещать одинаковую поисковую выдачу или восстановить прежнее содержимое каждого внешнего сайта. Повторный агент должен помечать новые/изменившиеся сведения и не приписывать их исходному срезу.

## Авторитет источников внутри комплекта

Для точного пересчёта: research/score.py + research/model.json + research/candidates.json + research/sources.json.

Для содержательной интерпретации исходного исследования: research/methodology.md и research/REPORT.md.

Для нового запуска: docs/WORKFLOW.md, docs/RESEARCH_RUNBOOK.md и согласованная конфигурация нового запуска. Противоречие между кодом и текстом документировать явно; не исправлять эталон задним числом.

Архив не передаёт права на сторонние публикации или описанные изобретения. Лицензия статьи и патентная лицензия — разные сведения.
