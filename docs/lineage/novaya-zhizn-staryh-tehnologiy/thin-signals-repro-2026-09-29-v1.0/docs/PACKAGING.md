# Сборка и проверка самого архива

Первоначальное исследование не менялось. Все 22 обычных файла скопированы в research/; содержимое сравнено побайтово. Служебный __pycache__ не включён.

К копии добавлены регламент, инструкции следующему агенту, схемы данных, шаблоны и независимые скрипты проверки. Затем:

1. Создан манифест файлов: `python tools/create_manifest.py`.
2. Выполнен `python reproduce.py` в отдельной временной рабочей папке.
3. Фактический результат и журналы этого запуска сохранены в validation/.
4. Манифест пересоздан для включения журналов.
5. Проверена целостность: `python verify_archive.py`.
6. ZIP собран из объявленных файлов: `python tools/build_zip.py --output ../thin-signals-repro-2026-09-29-v1.0.zip`.
7. Полученный ZIP отдельно распакован и проверен повторным запуском verify_archive.py и reproduce.py. Итог этой проверки сохранён рядом с ZIP в файле .verification.json.

Служебный скрипт create_manifest.py предназначен для сборки новой версии пакета. Не используйте его, чтобы скрыть несовпадение при проверке существующего архива. Нормальная проверка ничего не исправляет.

build_zip.py не перезаписывает существующий архив; для следующей версии укажите новое имя. Он включает только файлы манифеста и сам манифест, исключая пользовательские runs/. В ZIP фиксированное время записей; точное побайтовое совпадение повторно сжатого ZIP между разными версиями zlib не гарантируется. Целостность содержимого проверяется независимо от сжатия.

Контрольная сумма самого ZIP записывается в .zip.sha256 рядом с архивом. MANIFEST.json содержит контрольные суммы файлов внутри. Это два разных уровня проверки.

Если запускаете скрипты в исходной распакованной папке, для предотвращения создания байткода можно использовать `python -B ...`. Байткод не является частью эталона и не нужен для повторения.

validation/staging_replay_result.json подтверждает проверку перед финальной упаковкой. Внешний .verification.json подтверждает проверку уже распакованного итогового ZIP. Журналы не следует интерпретировать как новые научные эксперименты.
