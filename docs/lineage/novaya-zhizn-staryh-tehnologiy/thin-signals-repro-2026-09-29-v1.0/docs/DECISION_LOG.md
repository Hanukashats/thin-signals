# Журнал существенных решений

Это краткий аудит решений, восстановленный по сохранённым артефактам. Порядок логический; точные времена отдельных решений не фиксировались.

| ID | Решение | Основание и практическое следствие | Где проверяется |
|---|---|---|---|
| D01 | Разделить старый проект, долгую недокоммерциализацию и новую архитектуру старого эффекта | Возраст эффекта не доказывает, что современное изделие было готово десятилетия назад | methodology.md; history_class |
| D02 | Ввести два потока | Новые открытия не должны проигрывать из-за отсутствия истории | score.py: for_stream; тест нового потока |
| D03 | Допустить академические гранты как рабочую трактовку | Полностью «без денег» научные направления трудно определить; пользовательское уточнение не было получено | model.profile; PLAN.md |
| D04 | Отделить ворота от суммы баллов | Сильная наука не делает доступной уже занятую или закрытую реализацию | failures/holds; тест funded_business |
| D05 | Сохранять неизвестные как null | Отрицательный поиск не доказывает свободную нишу | A/W всех карточек; формула L/U |
| D06 | Проверить DOI программно | Снизить риск неверного названия/идентификатора; не подменять этим научный аудит | metadata_snapshot; metadata_doi_final |
| D07 | Сохранить неудачу Europe PMC | Ошибки 503 не превратить в фиктивный успешный сбор | metadata_snapshot.queries |
| D08 | Провести отдельный коммерческий проход по первоначальным 15 | Выявились противоречия, требующие замены пяти строк | market_search_log; retired_candidates |
| D09 | Добавить новые исследовательские направления с явными ограничениями | Нужна выдача 15 кандидатов без утверждения о 15 полностью квалифицированных возможностях | T16–T20; review_update |
| D10 | Оставить слабое историческое соответствие открытым | T19/T20 не должны выглядеть доказанными «проектами из архива» | history=2, historical_fit; строгий возраст |
| D11 | Проверить чувствительность весов | Определить устойчивость ранга к ограниченному изменению экспертных предпосылок | sensitivity.json |
| D12 | Выпустить 15 исследовательских карточек, 0 полностью квалифицированных | Коммерческие и правовые неизвестности не закрыты; тесты не выполнены | ranking.json; REPORT.md |

## Пять пересмотренных кандидатов

| Снятая карточка | Новое противоречие | Источники |
|---|---|---|
| T07: пироэлектрические генераторы | PYRO-E, коммерческий разработчик с финансированием | S58 |
| T08: вакуумная наноэлектроника | Финансирование Radiation Monitoring Devices | S59 |
| T12: водород из водорослей | Коммерческая история BHO и программа пилота Alg4Hyd с промышленным участником | S61, S62 |
| T14: ANE-датчики | Коммерческое предложение TL-Sensor | S60 |
| T15: терморадиационные диоды | Финансируемый коммерческий консорциум Phase II | S63 |

Эти решения снимают утверждение о свободном широком поле; они не доказывают закрытость всех будущих вариантов устройства. Для возврата нужен отдельный разбор иной реализации, актуальности бизнеса и доступности прав.

Добавлены T16 (жидкие мраморы), T17 (гибридные химические вычислители), T18 (солнечные лазеры), T19 (волновая механическая логика), T20 (ионная жидкостная память). Это замена набора, не установленное соответствие «одна конкретная замена на одного снятого».

Отдельно исключены искусственные реснички после обнаружения поставляемого MACplate (S64). Полный список 14 решений — research/exclusions.json.

## Ограничения журнала

Не сохранён отдельный полный исходный снимок всех карточек до каждой правки. Не следует запускать apply_review_update.py с ожиданием восстановить любой произвольный момент исследования. Он фиксирует конкретный проход добавления источников, новых карточек и причин снятия.
