# Проверка перед упаковкой

staging_replay_result.json и три файла .log — фактический результат запуска reproduce.py при подготовке комплекта. Проверялись исходные тесты, расчёт, пересборка отчёта, совпадение четырёх выходов и неизменность эталона.

На этом этапе манифест ещё не содержал сами журналы проверки и позднее добавленный инструмент проверки ZIP. Это нормальная последовательность упаковки: после добавления журналов манифест сформирован заново.

Отдельная проверка готового ZIP выполняется tools/validate_zip.py. Её результат находится рядом с итоговым ZIP в .zip.verification.json, поскольку он относится к уже сформированному архиву и включает проверку его фактической распаковки. Такой файл не добавляется внутрь проверяемого ZIP задним числом.

В журналах могут присутствовать пути рабочей машины. Они являются записями прошлого запуска и не нужны для исполнения на другой машине.
