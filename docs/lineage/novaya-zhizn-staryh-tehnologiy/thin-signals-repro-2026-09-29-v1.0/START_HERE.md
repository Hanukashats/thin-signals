# Тонкие сигналы — переносимый эксперимент v1.0

Это комплект для передачи другому агенту. Срез исходного исследования: **29.09.2026**. Версия исходной модели: **0.1-research**. Версия упаковки и документации передачи: **1.0**.

## Самый короткий путь

1. Распакуйте ZIP полностью, сохранив структуру каталогов.
2. Передайте агенту эту папку и текст `handoff/AGENT_PROMPT.md`.
3. Для проверки сохранённого результата выполните из корня:
   
   ```text
   python verify_archive.py
   python reproduce.py
   ```

Нужен Python **3.8+**, сторонние пакеты и интернет для этих двух команд не требуются. Команды работают в PowerShell, cmd и обычной оболочке Linux/macOS при наличии Python. Если команда называется `python3`, используйте её.

`reproduce.py` создаёт новую папку внутри `runs/`, копирует туда исследование, запускает 11 исходных тестов, пересчитывает ранги, чувствительность и отчёт и сравнивает их с сохранёнными эталонами. Каталог `research/` остаётся неизменным. Зелёный результат подтверждает воспроизведение вычислений, а не научную или инвестиционную состоятельность технологий.

## Содержимое

- **research/** — все 22 сохранённых исходных файла исследования, побайтовая копия: код, данные, отчёт, план, запросы, сетевые метаданные, промежуточный пересмотр и снятые карточки.
- **docs/** — документированный рабочий процесс, правила, оценивание, ограничения и критерии приёмки.
- **handoff/** — постановка задачи и готовое задание следующему агенту.
- **templates/** — формы новых карточек, доказательств, журналов и сравнения повторного запуска.
- **validation/** — фактический журнал проверки комплекта до упаковки.
- **verify_archive.py**, **reproduce.py** — проверка целостности и воспроизведение без изменения эталона.
- **MANIFEST.json** — размер и SHA-256 каждого файла комплекта, кроме самого манифеста. SHA-256 ZIP предоставляется отдельным файлом рядом с архивом.

## Состояние результата

15 исследовательских кандидатов; 14 записей исключений/отложенных решений; 83 источника; 43 DOI получены через Crossref; 20 сохранённых коммерческих запросов; 16 сценариев чувствительности; 11 тестов.

**Полностью квалифицированных коммерческих возможностей — 0.** Неизвестные права и финансирование не объявлены отсутствующими. Лабораторные тесты предложены, но не выполнены. Европа PMC вернула HTTP 503 на оба сохранённых поисковых запроса.

## Три разных значения «повторить»

- **Пересчёт:** те же карточки + тот же код дают те же ранги. Проверяется автоматически.
- **Повторная экспертная оценка:** другой агент оценивает те же свидетельства; различия объясняются и сохраняются.
- **Новое исследование:** другой агент заново ищет источники с выбранной датой среза. Состав 15 кандидатов может измениться. Совпадение списка не является критерием успеха.

Полная стенограмма всех поисковых вызовов и копии всех внешних страниц не сохранялись. Архив содержит все сохранённые материалы исследования и документированный процесс; пределы воспроизводимости перечислены в PROVENANCE.md.
