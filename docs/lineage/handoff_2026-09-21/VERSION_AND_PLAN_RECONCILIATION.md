## Что в сообщении Cursor согласуется с нашим планом

- Нужны radar 0.1.1, GoalOps, policy и тесты; они предоставлены.
- Формулы, критические gates, singleton и diversity уже разработаны; их надо перенести с условиями применимости.
- Автоматически ставить весь исторический стек или второй Auto-Goal daemon не требуется.
- 80% не было измеренным обещанием качества; reference tests и seed dataset не заменяют evaluation.

## Drop-list: удаление компонента и удаление функции — разные изменения

| Исключаемый компонент | Условие корректного решения |
|---|---|
| BERTopic, Kleinberg, GEPA | Допустимо отложить: сохранить discovery, aliases, singleton и прозрачные временные признаки |
| sklearn LogisticRegression | Не обязательно использовать именно его. Но требование ТЗ об обучении надо закрыть согласованным обучаемым компонентом либо подтверждённой иной трактовкой. Fine-tuning LLM для этого не обязателен |
| Neo4j | Можно заменить PG-таблицами nodes/edges и запросами. Требование графа связей с provenance и пользовательским просмотром сохраняется |
| S3 | Можно использовать защищённый файловый storage с hashes, backup и общим интерфейсом; snapshots не должны исчезнуть |
| OIDC/tenant | Можно отложить сложный multi-tenant продукт. Доступ к стенду/данным/операторским инструментам всё равно должен быть ограничен; публичный агент с правами backend недопустим |
| Procrastinate | Нужна конкретная замена доставки/сохранения run, retries, idempotency, cancellation, recovery. Она может уже существовать на backend; проверить её контракты |
| Refine/Cytoscape/Tiptap | Можно выбрать другой UI. Русские карточки, evidence inspector, граф/поиск и отчёт остаются требованиями пользователя |
| LangGraph/OpenCode dual adapters | Не требуются два параллельных runtime в первой реализации. Сохранить понятную границу выбранного исполнителя |
| Auto-Goal daemon | Исключение согласуется с v6.1 для runtime продукта; существующий контроллер разработки не удалять автоматически |

Это условия сверки, а не распоряжение вновь установить все перечисленные компоненты. Для каждой строки Cursor должен записать в v7.2: функцию, фактическую замену, приёмочный сценарий и основание изменения.

Утверждение о закрытии п.7.1 ТЗ или W2 проверяется по приложенному оригинальному PDF и артефактам конкретного прогона. Здесь не удостоверяется нумерация требований по одному резюме. 100 seed использовались для проектирования; они не являются нетронутым тестом. Новый набор 40–60 — проектный ориентир, не доказательство достаточности выборки и не заменитель формата организаторов.
