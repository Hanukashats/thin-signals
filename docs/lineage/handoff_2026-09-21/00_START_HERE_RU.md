# Передача Cursor: Thin Signals, доноры и уточнения

Собрано 21 сентября 2026 по запросу Павла Шаца. Версия этого архива — версия передачи, не новый план 7.3 и не новый релиз доноров.

## Что Cursor может использовать сразу

1. `donors/agispace-opportunity-radar-0.1.1/skills/agispace-opportunity-radar/` — полный исходный skill, references, template и validator.
2. `donors/goalops-universal-0.1/` — весь GoalOps: workflow, контракты ролей, schemas, gates, пример цели.
3. `reference/policy.py` + `reference/test_policy.py` — неизменённый код из v6.1; 15 тестов повторно прошли 21 сентября. Известные ограничения обязательны к исправлению при product integration.
4. `data/` — все 100 строк с паттернами, 18 механизмов, шесть предикторов, результаты прежних проверок.
5. `donors/product-opportunity-lab-MASTER-1.2.1/` — полная резервная сборка POL, включая source, исходные distribution ZIP, аудиты, patch, evals и тесты. По сообщению Cursor POL уже на ВМ: сначала сравнить, не перезаписывать.
6. `input/` — исходное ТЗ и XLSX; исходные имена/хеши в SOURCE_MANIFEST.json.

## В каком порядке читать

`CURSOR_HANDOFF_RU.md` → `VERSION_AND_PLAN_RECONCILIATION.md` → `METHODOLOGY_DONOR.md` → `KNOWN_GAPS_AND_ACCEPTANCE.md` → нужные references доноров.

`baseline/v6_1/` содержит полный предыдущий handoff и план. Его старые даты и технологические решения не надо молча применять поверх утверждённого нового плана. Полный v7.2 в доступных результатах поиска не найден; есть только переданное пользователем резюме Cursor. UUID ссылки Digest lineage donor plans не является доступным файлом плана в этом комплекте.

## Установка

Это архив передачи, без автоматического установщика и без изменений backend. Распаковать в отдельный staging-каталог, проверить SHA256SUMS. Выбрать нужные исходники под фактически установленный Cursor/Hermes. Для Cursor существующий стиль `.cursor/skills/<name>/SKILL.md` подтверждён сообщением оператора; проверить локальные AGENTS.md и механизм discovery перед подключением. Не копировать plugin manifest Codex в Cursor как предполагаемый универсальный installer.

Donor-файлы сохранены без правок. Копирование в продукт, исправления или создание производных skills выполнять в репозитории с сохранением происхождения и применимых лицензий. Полный архив Research Kit с посторонними исследованиями намеренно не дублируется; необходимая выборка извлечена из него.
