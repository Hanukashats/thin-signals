## Operations

From VM101:

```bash
ssh -i ~/.ssh/id_ed25519_homepve agent@192.168.5.231
ssh -N -L 8501:127.0.0.1:8501 \
  -i ~/.ssh/id_ed25519_homepve agent@192.168.5.231
```

The second command makes the UI available locally at `http://127.0.0.1:8501`.
Service verification on the guest:

```bash
systemctl is-active agi-sing-box thin-signals-api thin-signals-ui
curl -fsS http://127.0.0.1:8095/ready
curl -fsS http://127.0.0.1:8501/_stcore/health
docker compose -f /opt/thin-signals/compose.yaml ps
```

Code synchronization remains Git-only: commit and push to SourceCraft, then
`git pull --ff-only` on the guest. Only ignored secrets and backup archives may
be copied outside Git.

For a clean Ubuntu guest, the matching bootstrap invocation is:

```bash
VM_HOSTNAME=agi-thin-signals-v2 ENABLE_SING_BOX_REDIRECT=1 \
  bash scripts/vm230-bootstrap.sh
```

The redirect flag adds the Docker-to-host UFW path required by the separately
installed sing-box service; it does not open API or UI ports.

all VM state newer than that snapshot; confirm the target first.
