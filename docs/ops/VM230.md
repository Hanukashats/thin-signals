## Доступ агента с VM101

`~/.ssh/config` у `cursor-agent`:

```
Host home-pve            # root@10.200.200.41, ключ ~/.ssh/id_ed25519_homepve_p0005 (копия P0005 из /root/private-access)
Host vm230 agi-thin-signals   # agent@192.168.5.230, ключ ~/.ssh/id_ed25519_homepve, ProxyJump home-pve
```

`ssh vm230`, `ssh home-pve 'qm terminal 230'`. После вступления VM230 в NetBird ProxyJump можно убрать (HostName → mesh IP).

## Правило параллельной разработки

Правка → `git commit` → `git push` (GIT_ASKPASS=`.secrets/git-askpass.sh`) → на другой стороне `git pull --ff-only`. Никакого rsync/scp кода между VM101 и VM230; переносятся только git-ignored секреты и архивы. Перед крупными правками: `ssh home-pve 'qm snapshot 230 pre-<дата>'`.

Pre-push hook (`scripts/git-hooks/pre-push`, ставится `scripts/install-hooks.sh`): pytest + check_living_links.

## Восстановление

- Откат ОС: `qm rollback 230 bootstrapped` (теряется всё после снапшота; репо — с SourceCraft, секреты — с VM101 `/opt/thin-signals/.secrets`).
- Откат egress: `sudo systemctl disable --now agi-sing-box` (fail-open на домашний IP).
- Пересборка с нуля: Ш1 команды `qm create/set` из `reports/vm230-provisioning-2026-09-23.md`, затем `scripts/vm230-bootstrap.sh`.
