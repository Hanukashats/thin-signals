## Operations

```bash
systemctl is-enabled thin-signals-api thin-signals-ui \
  thin-signals-research agi-sing-box docker
systemctl is-active thin-signals-api thin-signals-ui \
  thin-signals-research agi-sing-box docker
./scripts/vm232-research-contour.sh status
curl -fsS http://127.0.0.1:8095/ready
curl -fsS http://127.0.0.1:8501/_stcore/health
```

Rollback is explicit and non-destructive:

```bash
./scripts/vm232-research-contour.sh rollback
```

It disables the research unit, restores the API drop-in without SearXNG and
preserves images/data for diagnosis. Product database and UI are not deleted.

## Known limits

- GPT Researcher upstream dependencies use version ranges. The source commit
  and resulting image are pinned, but rebuilding later can resolve newer
  transitive packages; retain the built image until a lock strategy is added.
- The GPT Researcher request forces OpenRouter ZDR/no-collection policy, but
  that upstream does not independently validate the returned provider. Its
  output is advisory. The product's own checklist client still performs the
  strict provider validation and records model/provider provenance.
- NetBird VM233 is deliberately separate. Its control plane is healthy, but
  peer enrollment and recreated access policies remain a separate unfinished
  network task.
- The researcher/critic/defender/control-critic contracts, deterministic arbiter,
  append-only review ledger and product wiring are implemented on the reliability
  branch. They are not active on VM232 while
  `TS_ADVERSARIAL_REVIEW_ENABLED=false`; activation remains gated by the frozen
  replay/holdout evaluation and a bounded live canary.
- The tested SearXNG queries returned results only from `google cse`. Direct
  product connectors still provide independent sources, but metasearch engine
  diversity is not claimed. The upstream image also logs the same Ahmia/Torch,
  ownership and limiter warnings on both the old and new pins; current JSON
  search and health are unaffected. Treat removal of those warnings as a
  separate configuration-hardening change.
